这三个产物描述的是公开 NWNHT 记录中“先出手方”的观察数据；不是已证明能赢的策略，也不是 PhysX 出手参数库。

## 为什么不用 v1 效果标签

`nwnht_first_player_board_effects_v1.jsonl` 保留以便追溯，但不再作为后续分析输入。复核发现 `end_id=9972, K=5`：两颗不同颜色的最近壶在上游 CV 坐标中距离圆心相同，旧逻辑依赖浮点结果与字符串排序，把它强行标成“己方夺得得分控制”。

v2 的修正：

- 最近异色壶到圆心之差不超过 0.005 m 时，标为得分控制不确定，不把它归为任何一方的得分控制；这是对 CV 坐标的保守弃权规则，不是正式比赛量分规则。
- `scoring_count` 只计算真正位于对方最近壶以内的壶，不再把同一颜色所有营内壶都算作得分壶。
- 不覆盖 v1；v2 使用新的文件名和审计样本。

v1 到 v2 一共改动 106 / 86,984 条主标签，全部是原来的 `GAIN_OWN_SCORING_CONTROL` 降级为其他可观察效果：46 条补己方营内层、1 条补己方守壶、52 条减少对方营内层、7 条无可分类宏观效果。

## 仍未验证，不能夸大

- 180 条只是为人工查看准备的分层样本，尚未逐条对照原始比赛画面判定“正确 / 模糊 / 错误”。
- 此复核不能证明 SQLite 上游视觉识别的壶坐标和原始画面完全一致。
- 盘面效果是 `S -> U` 的观察标签，尚不是可干预的战术动作；还没有完成混杂控制、反事实评估、对手反应建模或策略胜率证明。
- 0.005 m 是保守数据标注阈值，需要在后续做阈值敏感性分析；不能当成真实冰壶规则或 PhysX 碰撞容差。
