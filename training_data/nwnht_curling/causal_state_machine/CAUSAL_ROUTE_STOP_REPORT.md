# NWNHT 观察壶谱因果策略路线：停止报告

## 结论

截至当前数据与验证门，不能从 NWNHT 的观察壶谱中发布任何可部署的先手固定策略边。

这不是“没有跑出策略”，而是按预先设定的隔离保留集门槛主动拒绝了两种不充分的动作定义。继续在同一数据、同一结果标签和同一选择流程上反复调参会扩大选择偏差，不能增加证据等级。

## 已验证的两条路线

| 路线 | 处理定义 | 开发集信号 | 隔离保留集结论 |
| --- | --- | --- | --- |
| 效果代理 | 投后 `ADD_OWN_HOUSE_LAYER` 等盘面效果 | 有少量 bootstrap/置换候选 | 冻结局部图 IPW 区间 `[-0.0485, +0.0826]`，拒绝 |
| 意图代理 | 上游叫球家族，如 `DRAW_TO_HOUSE`、`GUARD` | K2 的 `DRAW_TO_HOUSE > GUARD` 通过开发筛查 | IPW 区间 `[-0.0492, +0.0677]`，拒绝 |

两条路线均按 `match_id` 切分，开发折为 0–3，折 4 从候选选择中隔离。

## 已确认而非猜测的问题

1. **效果代理不具可干预性。** 它是出手后成功实现的壶面结果，规划器不能直接选择；只能把它当中介/目标结果。
2. **意图代理可发生在出手前，但不是运行时动作。** 上游叫球文字是记录代理，不是本地 PhysX 的目标区域或 `v/h/w`。
3. **保留集并非完全无覆盖。** 候选状态和目标动作在折 4 中仍有样本，失败不能简单归咎于状态消失。
4. **当前 OPE 信息量有限。** 意图候选触发 118 个 end、实际路径匹配 50 个；区间覆盖零，不能诚实写成优势。

## 必须新增的证据源

下一阶段不能再只调整统计模型。需要至少一个可干预层：

1. **本地 PhysX 反事实库（推荐）**：对高支持状态生成少量可达目标区域/出手，记录 `intent/target -> realized effect -> opponent response search -> end proxy`；这给出真正可执行的处理定义。
2. **带出手目标或投壶轨迹的外部记录**：用于把历史叫球代理替换成几何目标类别。
3. **人工审计的高价值局面集**：核对意图、目标和下游效果，先解决标签有效性，再估计因果价值。

在新的可干预证据加入前，运行时输出应保持 `SEARCH_REQUIRED`，并继续使用独立的公开战术/PhysX 启发式作为**非因果、待验证**候选，而不得声称数据证明其能赢。
