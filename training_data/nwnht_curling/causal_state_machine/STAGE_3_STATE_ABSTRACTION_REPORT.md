# 阶段 3：先手局面状态抽象报告

## 结论

当前可以把任意“第 K 次先手出手前的壶坐标”稳定映射到一个可解释的 `CORE` 状态，但它还不是可直接执行的策略状态机。

- 全部 86,984 条先手记录得到 2,691 个 `CORE` 状态、9,207 个 `FINE` 状态。
- 只有 181 个 `CORE` 状态达到 100 条样本支持；其余应在运行时回退为 `SEARCH_REQUIRED`，不能硬套历史结论。
- 266 个“状态—己方盘面效果”单元同时有基本训练/跨比赛保留样本；152 个的对手回复和下一状态分布在该筛查阈值下未见明显漂移。
- 这不是因果价值，也不是推荐动作。`observed_own_effect` 是投后壶面事实标签，不能直接当作人类可随意指定的随机处理。

当前有效工件：

- `artifacts/nwnht_first_player_causal_state_abstraction_v1.json`
- `artifacts/nwnht_first_player_state_homogeneity_screen_v0.json`

`...state_abstraction_v0.json` 因 `fine_substate_count` 的报告字段前缀匹配错误而废弃为诊断输入；它不影响其中的核心状态数和边统计，但不能继续引用其细状态计数。v1 不覆盖 v0，已修复该字段。

## 运行时状态定义

状态只使用 `K=1..8` 与当前壶坐标推导的下列离散特征：

- 当前得分控制：己方、对方、空营或近似平手/不确定；近似平手沿用 v2 的 0.005m 保守弃权规则。
- 双方营内壶数（0、1、2+）。
- 双方中线守壶数（0、1、2+）。
- 双方侧翼守壶数（0、1、2+）。

细状态额外保留双方可见壶数、以及“同色前置守壶在 0.42m 横向范围内”的保护代理。这个代理只描述几何遮挡；它**不表示后方壶安全或不可被处理**。

比分、局号、队伍、赛事、叫球文字、投手评分和终局结果均不进入 `state_id`。

## 支持度分布

| K | CORE 状态数 | 达到 100 样本的状态数 |
| --- | ---: | ---: |
| 1 | 1 | 1 |
| 2 | 17 | 14 |
| 3 | 124 | 31 |
| 4 | 326 | 29 |
| 5 | 457 | 27 |
| 6 | 537 | 27 |
| 7 | 594 | 28 |
| 8 | 635 | 24 |

这说明不能把早期少数高频局面和后半局复杂盘面混成一个“小而全”的固定状态机。当前正确做法是：高支持状态进入因果估计候选池，低支持状态保留坐标并交给后续搜索，不编造策略边。

## 核心状态内部的异质性筛查

按 `match_id` 分组切出训练/保留集。在相同 `(CORE 状态, 己方盘面效果)` 内，比较不同 `FINE` 子状态的**对手回复效果分布**；只有训练和保留集的总变差距离都至少 0.25，且子状态与其余状态均有足够样本，才判为稳定分裂。

266 个可筛单元中：

- 3 个 `STABLE_HETEROGENEITY_SPLIT`：后续不能把它们按 CORE 合并估计；
- 49 个 `NO_STABLE_HETEROGENEITY_DETECTED`：暂未发现稳定差异，不是等价证明；
- 214 个 `INSUFFICIENT_FINE_SUPPORT`：证据不足，不能宣称完成合并。

三个已确认不可合并的单元：

1. K3，己方当前控制、双方各一营内壶、己方一中线守壶、对方一侧守壶；己方效果为 `ADD_PRESSURE_GUARD`。己方营内壶是否被同色守壶代理保护，会稳定改变对手回复分布。
2. K3，对方当前控制、对方一营内壶、己方一中线守壶、对方一侧守壶；己方效果为 `GAIN_OWN_SCORING_CONTROL`。可见壶数与保护代理不同，回复分布稳定不同。
3. K8，对方当前控制、对方一营内壶、无守壶；己方效果为 `GAIN_OWN_SCORING_CONTROL`。双方可见壶数不同会稳定改变对方最后一壶的处理类型。

这三点支持“终局不能只看谁最近”，但不代表任何一个防守构型绝对安全。

## 下一阶段准入条件

阶段 4 的双重稳健估计只可从以下集合开始：

- 有 `min_state_support=100`；
- 对该效果有至少 25 条训练、10 条保留样本；
- 不属于上述 `STABLE_HETEROGENEITY_SPLIT`，或改用对应的 FINE 状态；
- 将队伍/赛事等仅作为离线混杂校正变量；绝不写入运行时状态。

仍需要：重叠诊断、倾向模型、结果模型、反驳与敏感性分析，之后才能判断是否存在可支持的策略边。
