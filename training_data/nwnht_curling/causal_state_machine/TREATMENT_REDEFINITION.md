# 动作定义修正：效果不是动作

效果代理策略在隔离保留集 OPE 中未通过，且存在更根本的可执行性问题：`ADD_OWN_HOUSE_LAYER`、`GAIN_OWN_SCORING_CONTROL` 等是在出手后观察到的壶面结果。规划器只能选择意图、目标区域和 `v/h/w`，不能直接选择“已经成功的结果”。

因此后续因果模型必须使用两层：

```text
投前局面 S + 出手前意图 I -> 实现的壶面效果 A -> 对手回应 B -> 终局 Y
```

- `I`：先用上游叫球家族作为审计用预处理代理；不能直接进入运行时。
- `A`：保留为实现结果/中介变量，用于学习目标区域、成功率和对手回应。
- 运行时最终应以从壶位学习的目标区域替代 `I`，再由 PhysX 判断可达性。

这不是把叫球文字偷换成策略。它只是避免把出手后的成功结果错误地当作可干预动作。
