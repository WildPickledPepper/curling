# 先手八步状态图：重新聚类定义

状态只定义为：`(先手第 k 次出手, 当前壶面战术形态)`，其中 `k=1..8`。第 `k` 次对应总第 `2k-1` 手。

不进入状态特征：比分、局号、胜负、领先落后、控分/blank 偏好、真实比赛规则。它们不参与聚类，也不参与本图的动作推荐。当地模拟器的固定规则由运行时根据 `k` 验收；NWNHT 只提供历史壶面和观察到的叫球。

每个 `k` 单独聚类。拓扑特征包括双方可见壶数、营内/守壶/中线壶、近似受保护营内壶、四个纵深区域与左中右位置的占位、暂得分方和最近营内距离。左右镜像会规范成同一特征，具体从左还是从右由后续 PhysX 规划决定。

簇数不再由几何 BIC 单独决定。按 `match_id` 整场留出约 20% 比赛，对每个候选 `k` 用训练比赛拟合几何簇，再测该簇对留出比赛中历史叫球的预测负对数似然；采用“一标准误差规则”，在接近最佳预测能力的候选中选最小的 `k`。历史叫球只用于检验“这个几何划分在陌生比赛里是否仍是稳定决策区分”，不等于推荐该叫球。

一条边是：

`(k, 壶形) --本方历史动作 / 对手历史回应--> (k+1, 新壶形)`

第八次先手出手的边落到 `TERMINAL_AFTER_OPPONENT_REPLY`，不写入胜负或得分目标。

输出中的动作和回应均是历史记录频数，不是推荐。只有在后续本地 PhysX 验证过可达性和本地规则合法性后，某个节点才可变成策略树节点。
