# 先手宏观状态机

这是新的可部署离散层：

`状态 = (先手第 k 次出手, 宏观壶形)`，`k=1..8`。

它不使用比分、局号、胜负、控分/blank 或外部规则资料。当前营内谁的壶更近仅是壶面几何关系，不是比赛比分。

## 宏观壶形

按优先级判定：空场；高密度营内缠斗；对方中线壳；己方中线壳；对方营内威胁；己方营内控制；守壶交换；低壶数开放；混合对抗。

默认要求同一个 `Kk × 宏观壶形` 至少有 250 条历史样本。达不到的罕见组合会合并成 `LOW_SUPPORT_SEARCH_REQUIRED`：它保证运行时仍有确定路由，但不允许离散层从很少数据中编造战术规则。该回退节点本身可以少于 250 条，因为它没有独立学习出的战术含义。

高密度营内缠斗、中线壳和低支持度回退会明确标记 `physx_detail_required=true`。它们不是“安全构型”，而是说明离散层不再继续虚构微观状态；具体窄门、撞击链、raise/runback 和 `v/h/w` 由严格 PhysX 搜索决定。

## 输出边

每条边记录：

`(Kk, 宏观壶形) -- 本方历史动作 / 对手历史回应 --> (K(k+1), 新宏观壶形)`

历史动作仅作频数证据，不是策略推荐。合法性始终按本地规则和 `k` 在后续规划时验收。
