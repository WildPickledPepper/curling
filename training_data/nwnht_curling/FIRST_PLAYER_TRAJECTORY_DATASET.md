# 先手状态机的逐局轨迹数据集

状态图不是把 47 个状态孤立摆在一起，而是从每个 end 的连续八步轨迹构建：

```text
S1 → A1 → R1 → S2 → A2 → R2 → … → S8 → A8 → R8 → terminal
```

- `Sk`：先手第 k 次出手前的宏观状态；
- `Ak`：历史记录的本方叫球；
- `Rk`：紧随其后的对手叫球；
- `S(k+1)`：对手回应后、下一次轮到先手时识别出的状态。

每一行额外保留两种结果标签：

- `end_result` / `end_points`：这一 end 中先手方得分、对方得分或 blank；
- `game_result` / `final_game_score`：以该 end 首手方视角记录整场 WIN / LOSE / DRAW。

这些字段不进入 `state_id`，也不参与状态识别。它们用于之后审计“某类历史路径最后发生了什么”，不能直接被误读为“某动作导致赢球”。同一几何状态在不同比赛中可带不同最终结果，这正是必须保留原始逐局轨迹和结果标签的原因。
