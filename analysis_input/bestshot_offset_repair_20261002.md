# BESTSHOT 非零偏移：出手坐标分叉已修复

2026-10-02，修复样例 11009 在第一帧物理步之前的主冰壶 Z 坐标 1 ULP 差异。生产 `start_bestshot` 现在直接以已观察的原生基准 Z 做 float32 减法，保留 float32 偏移解析/范围限制，不再经过协议坐标的加减换算。
