# 第一名平局日志：逐手转场回放（2026-07-26 15:49）

## 能回答什么

两份压缩包中，`6a647b2a...-1.log` 是我方提交包的完整遥测；`6a5f70d0...-2.log` 只有中文噪声式输出，没有对方的 `BESTSHOT`、出手参数或逐手遥测。

本次不猜测对手内部 PPO 的战术标签。每次我方严格出手的日志都记录了：出手前壶面、实际执行的 `v/h/w`、以及三条 PhysX 摩擦种子。将我方这一手按三种子严格回放，再与下一张“对方出手后、我方准备出手”的日志壶面对比，得到的是**对方可观察到的壶面效果**：清走了什么、推动了什么、以及对方新壶最终在哪里。

## 覆盖与限制

- 可回放转场：`47`。只包含日志中有三条 PhysX 种子的非末手严格出手。
- 未覆盖普通模板球：它们没有记录严格 PhysX 种子。
- 每个转场按三种已记录种子回放；`44 / 47` 的效果分类在三种子下完全一致，余下 `3` 条为 `2 / 3` 一致。
- 历史日志没有保存各壶 yaw，也没有保存平台实际执行的唯一物理状态；回放统一以 yaw=0 复原。因此这里用于判断“清/撞/推/单纯落位”等可见效果，**不能倒推出对手精确 `v/h/w`，也不能等同于其内部战术意图。**
