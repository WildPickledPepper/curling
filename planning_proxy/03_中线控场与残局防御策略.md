# 中线控场、战略清除与残局防御策略

## 目的

本策略面向**我方先手**的一局八轮对局。它的目标不是每一颗壶都做独立的“清场”决定，而是：

1. 前五次投壶利用中线规则，稳定处理对方已进入主战区的壶；
2. 让己方壶逐步形成不聚堆、难以一杆连锁清掉的得分布局；
3. 第六颗起，将“清掉对方壶”和“把自己滚到防御位置”合为同一次撞击；
4. 把局面导向少数预先验证过的防御球形，而不是每次从无数可能球形中重新盲搜。

本文只描述非扫冰策略。最终每一条出手仍必须由严格 PhysX、多条摩擦序列和规则过滤复核。

## 先统一计数方式

下文的“我方第一颗、第二颗、……第八颗”指的是我方在本局投出的第几颗壶；“对方第五颗”同理。

自由防守区和中线规则看的是**全场前五次投壶**，不是双方各自前五颗，也不是前五轮：

```text
第一轮：我方第一颗 → 对方第一颗
第二轮：我方第二颗 → 对方第二颗
第三轮：我方第三颗 → 对方第三颗
```

我方第三颗是全场第五次投壶；它投完以后，保护规则解除，对方第三颗起可以正常清中线守壶。

## 规则和坐标边界

大本营圆心是 `(2.375, 4.880)`；壶半径为 `0.145 m`。比赛端以壶的**中心点**判断普通出界：

```text
0.145 < x < 4.605
2.865 < y < 10.525
```

中心点达到或越过任一边界，壶会被物理移除。

前五次投壶内：

- 对方位于自由防守区的普通守壶可以被击打和推动，但不能被打出界；
- 对方位于自由防守区且触及中线的守壶，除不能出界外，也不能被撞离中线、不能被撞进大本营；
- 己方自己的中线守壶不受“不能击打”的限制；己方可以碰自己的壶。

因此，中线守壶并非不可触碰的盾牌。它的实际价值是：在保护期内，对方无法用一杆把它从中线路障变成无害位置。

## 物理出界与战略出界

策略上要区分两件事。

### 物理出界

壶被比赛端删除，完全不再参与后续碰撞。这是最干净的处理结果。

### 战略出界

壶仍在 PhysX 场景中，但已不能有效得分、挡住主通道或回到主战区。它在策略评分中可以视为“已处理”，但**不能从物理场景删除**。

当前有两种战略出界候选。

#### 边缘废球

对方普通自由防守区壶在前五次投壶内不能直接打出界时，将其推入左右边缘带：

```text
左侧：0.195 ≤ x ≤ 0.435
右侧：4.315 ≤ x ≤ 4.555
```

这里刻意避开真实出界线 `0.145 / 4.605` 至少约 `5 cm`，避免摩擦随机性把对方壶误打出界而犯规。边缘废球的含义是：它仍在场，但已远离中路；对方若想重新让它参与主战区，通常要专门耗一颗壶，并承担较高的出界或失去得分机会的风险。

#### 大本营后方废球

“在圆心后方”不等于废球。例如 `y=4.70` 虽然在圆心后方，却仍非常接近中心、完全可以得分。

只有壶中心已经越过大本营**最靠后的得分边缘**，才可视为后方废球：

```text
y ≤ 4.880 - (1.830 + 0.145) = 2.905
```

它已经不能触及大本营得分区；物理出界线是 `y ≤ 2.865`。因此“物理仍在场但在大本营后方”的带只有约 `4 cm`，不能把刚越过画出的后圆边缘误判为安全废球。

### 策略使用原则

对方一颗壶若在每条摩擦序列下满足以下任一项，可在策略评分中记作“已处理”：

1. 物理出界；
2. 进入边缘废球带；
3. 进入大本营后方废球带。

但最终优先级是：

```text
不犯规、己方防御阵型不散
    > 对方战略出界
    > 在阵型同样好的情况下，对方物理出界
```

物理出界仍是同等阵型下的优选，因为该壶以后绝不会再参与碰撞。

## 前五次投壶：简单、稳定地建立基础

### 第一轮

我方第一颗放中线守壶，例如参考位置：

```text
G = (2.375, 7.15)
```

对方第一颗可能进大本营，也可能摆普通自由防守区守壶。

### 第二轮：我方第二颗

处理对方第一颗，同时让自己的出手壶尽量停在红圈中心附近：

```text
对方第一颗进大本营：打出界；
对方第一颗在普通自由防守区：推成边缘废球；
我方第二颗：尽量进入红圈，成为当前最接近中心的己方壶 H1。
```

若“处理对方壶”和“自己进红圈”无法同时稳定做到，优先顺序是：规则合法、己方不丢壶、对方不占红圈、再靠近红圈目标。

### 第二轮后：对方第二颗的主要反制

对方第二颗的有效选择可归为四类：

| 对方做法 | 目的 | 我方第三颗的主要回应 |
|---|---|---|
| 直接进大本营 | 抢中心、逼我方处理 | 能清则清；否则投得比它更靠中心。 |
| 再摆普通自由防守区壶 | 堵路线、铺后续布局 | 推成边缘废球，或绕另一侧补红圈壶。 |
| 绕过中线守壶攻击 H1 | 清除我方当前得分 | 根据撞击结果，优先重新取得“最近壶”位置。 |
| 轻碰中线守壶 | 改变中线路障位置 | 它仍必须在中线自由防守区；我方继续补红圈，不为此浪费一颗壶。 |

对方攻击 H1 时，不能只看 H1 是否还在场，而要先看**谁离中心最近**：

- H1 被打出界、对方出手壶也出界：我方第三颗重新占红圈；
- H1 被打出界、对方出手壶停在红圈：我方第三颗优先处理该对方壶，或投得比它更近；
- H1 被推出红圈但仍在大本营，且 H1 仍比对方近：不急着救 H1，直接补另一侧红圈壶；
- H1 被推出红圈且对方壶更近：我方第三颗要重新夺回最近壶，不能只追求“红圈里壶更多”。

### 第三轮：我方第三颗后的基础阵型

我方第三颗是全场保护期内的最后一颗。目标不是把己方壶堆在圆心，而是形成：

```text
前方中线：中线守壶 G
红圈内：一颗最接近中心的得分壶 H1
红圈内：另一颗前后、左右错开的得分壶 H2
对方：没有有效主战壶；最多有边缘废球
```

可用作搜索吸引目标的一组参考坐标：

```text
G  = (2.375, 7.15)
H1 = (2.28, 4.70)  # 中心略后、略左，当前得分锚点
H2 = (2.67, 5.18)  # 中心略前、略右，第二层得分壶
```

若左侧有障碍或边缘废球，则使用镜像布局：

```text
H1 = (2.47, 4.70)
H2 = (2.08, 5.18)
```

这不是要求每颗壶必须停在毫米级固定坐标，而是要求三种相对关系：

1. 有一颗己方壶最接近中心；
2. 第二颗己方壶留在红圈另一侧；
3. 两颗红圈壶前后错层、左右也错开，不与中线守壶排成一条可连锁撞击的直线。

## 第六颗：清对方第五颗，同时构造防御

假设对方第五颗刚投完，轮到我方第六颗。现在规则保护已经解除，因此对方第五颗若有威胁，应优先将其物理打出界；若物理清除会明显撞散我方阵型，则允许把它送入战略出界区。

第六颗不是普通击打，而是**击打后滚位**：

```text
第一个目标：对方第五颗已处理；
第二个目标：我方第六颗留在场内，滚到前方偏侧保护位。
```

它不应继续死压红圈中心，也不应停在空旷位置。这里不把“防御三角”写死成一个
坐标：搜索器按己方当前在场壶数同时尝试几个**可替代**的形状，严格 PhysX 只要
稳定实现其中一个就可保留。候选如下：

| 己方当前在场壶数 | 可接受的防御形 |
| --- | --- |
| 1 颗 | 双红圈错层、左侧护门、右侧护门 |
| 2 颗 | 左侧三角、右侧三角、第三红圈错层 |
| 3 颗及以上 | 左侧外壳、右侧外壳、红圈后备 |

其中“左/右”只是两条不同的防线，不要求同时完成；最终根据碰撞后的完整度和多条
摩擦序列下的最差结果选其中最稳的一条。一个典型的防御三角可以是：

```text
投壶方向
    ↓

       H6 ●             第六颗：前方偏侧保护壶

                 H2 ●   前方偏侧红圈壶

          H1 ●          后方、接近中心的得分壶
```

- `H1`：当前最接近中心，负责得分；
- `H2`：红圈内第二层，和 H1 错开；
- `H6`：比 H1/H2 更靠前、位于另一侧，负责阻断最容易的直线击打。

第六颗严格候选只有同时满足以下条件才可视为成功：

1. 对方第五颗在每条摩擦序列下均已物理或战略出界；
2. 所有原有己方壶仍在场；
3. 我方第六颗仍在场；
4. 我方仍有至少一颗最近壶；
5. 我方仍有至少两颗红圈壶；
6. H6、H2、H1 没有排成一条可被一杆连锁撞击的直线。

## 第七、八颗：修复而非贪心

第六颗后，对方每一颗新壶都必须先被当作本轮待处理对象。规则保护已经解除：若它仍是有效壶，我方第七、八颗先搜索“**清掉这颗对方壶，同时修复被拆层**”的击打滚位；只有严格 PhysX 在多条摩擦序列下找不到这种两项目标兼得的候选时，才退到“先保住最近壶/己方阵型”的修复球，不能把对方上一颗壶当作不存在。

在上述前提下，对方会尝试拆三角的一层。第七、八颗要修复的层为：

| 对方拆掉的部分 | 我方优先修复 |
|---|---|
| 最近壶 H1 被威胁或清掉 | 重建一颗比对方更近的得分壶。 |
| 第二层红圈壶 H2 被清掉 | 在另一侧补红圈壶，避免与 H1 同线。 |
| 前方保护壶 H6 被清掉 | 补新的前方偏侧壶，恢复对直线击打的阻挡。 |
| 对方仅摆出边缘/外圈壶 | 不为清无效壶浪费机会，继续保住最近壶和两层红圈布局。 |

我方是先手时，对方拥有本局最后一颗壶，因此本文不宣称“形成该壶型即可稳赢”。正确目标是让对方最后几颗壶每次只能拆一层，而我方仍能在下一颗壶修复；同时尽量保持我方最近壶更近、红圈己方壶更多。

## 规划器应如何实现

1. 严格 PhysX 始终保留所有物理在场壶，包含边缘废球和后方废球；
2. 每条候选、每条摩擦序列都计算“对方有效壶数”，而不只计算 `enabled=false` 的物理出界数；
3. 对方壶在边缘/后方废球带时，策略评分把它记作已处理，但碰撞、规则和正式计分仍使用真实状态；
4. 前五次投壶中，普通自由防守区对方壶的合法处理目标是边缘废球；中线守壶不可作为这种处理目标；
5. 第六颗起，筛选“击打后滚位”候选：先满足对方第五颗已处理，再按防御三角的完整度排序；
6. 每个球形要接受对方下一颗最强反击搜索，以及多条摩擦序列复核；未经这一步，不把“边缘废球救不回来”写成绝对结论。

## 当前待验证项

- 边缘废球带中，对手一颗壶是否能稳定让原边缘壶重新回到有效中路，同时自己仍取得得分；
- 对方绕过中线守壶攻击 H1 时，可行输入范围与成功率；
- 第六颗“清对方第五颗并滚到前方偏侧”的实际可达区域；
- 防御三角面对对方第六、第七、第八颗的最强反击时，能否持续保住最近壶或两颗红圈壶。

这些验证完成前，本文是明确的策略假设和实现规格，不是胜率保证。
