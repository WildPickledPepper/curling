# 双飞的匿名全盘终局构型契约

## 为什么不能忽略出手壶落点

双飞后，出手壶和已有己方壶都可能移动。NWNHT 的同色壶没有跨帧 ID，因而
`active_final_point = null` 的准确含义是“无法可靠识别本次出手壶”，不是
“落点不重要”或“出手壶一定出界”。

正确的双飞终局是：

```text
两个当前绑定的对方壶：均 OUT_OF_PLAY
+ 整个己方/对方匿名终局壶面：满足某个 v2 post-own topology
```

拓扑同时约束按钮、四个营内扇区、双方保护壶、最近壶控制和宏观形态。严格
PhysX 有真实 slot；未来多目标求解时，可同时检查这两个实际 target slot 和
历史数据支持的匿名整盘构型。

## 五折支持

比赛按 `match_id` 确定性分为五组。同一比赛不会跨组；一个拓扑的
`support_by_match_fold=[a,b,c,d,e]` 是它在五个独立比赛组各出现的次数。

- `[3,3,1,4,2]`：总支持 13，五组均出现，说明该构型不是只来自单一比赛组；
- `[0,2,1,2,0]`：总支持 5，但两组未出现，不能称为跨比赛稳定；
- 它只检验复现性，不证明双飞的因果价值、胜率、物理可达性或末壶防守安全。

## 双飞后继形态与终局标签（v2 证据字段）

新工件 `nwnht_v2_double_outcome_goal_contracts_v2.json` 保留原先的终局约束，另外
为每一个分支记录该分支历史轨迹的 `first_end_margin` 和 `FIRST_SCORES / BLANK /
OPPONENT_SCORES` 分布。它回答“历史上这种后继形态后来怎样结束”，不回答
“主动选择这个形态会因果地导致什么”。

| 来源 | 双清后宏观形态 | 支持 / 五折 | 平均本局差 | 先得分 / blank / 对手得分 |

| K7 对方营内威胁 | EMPTY | 8 / `[3,1,1,1,2]` | 0.000 | 1 / 6 / 1 |

或局数输入的当前模型也不能把 blank 当作特定比赛语境下的收益；这里只记录事实。

## 目标级五折排序的处置

双飞分支现已进入更严格的 `S -> A -> G` 五折倒推。门槛是：G 本身在五个比赛折均
有观测，且同一个 G 在至少 4/5 外层留出折中成为该状态的历史首选。K7 与 K8 的
`OPPONENT_HOUSE_THREAT` 都没有通过该门，因此运行时状态机必须返回
`SEARCH_REQUIRED_NO_CROSS_FOLD_GOAL_OUTCOME_CONSENSUS`，而不是推荐 EMPTY、
GUARD_EXCHANGE 或任一双飞路线。

这不是否定“某个双飞在某一局可打”，而是拒绝把目前样本量和稳定性不足的双飞形态
包装成可复用策略。严格 PhysX 的双清冒烟记录继续保留为执行层证据，但不参与该
战术推荐的越权兜底。

## 已有与未有

- 已有：目标双壶动态绑定、匿名全盘终局拓扑、镜像归一化后的严格终局谓词；
- 已有：独立的多目标 MADS。它同时验收两个实际 target slot 出界和整盘拓扑，
  不复用单目标 hit-and-roll 的“清到一颗就算成功”判据；
- 未有：父动作跨折价值共识和 K8 对手末壶反击筛查。

因此这些契约已经补齐“应该验收什么”，但尚未声称“已经找到怎样投双飞”。

## 多目标 MADS 第一条严格 PhysX 冒烟

新增 `double_mads_solver.py`，其目标函数不调用旧单目标清壶评分，而是每条
严格 PhysX 序列同时惩罚：

1. 两个绑定 target slot 中仍在场的数量；
2. 匿名整盘终局特征与本双飞分支的差异；
3. 自由防守区等规则违规；
4. 在前述条件相同下的己方出界数。

K8 “清双后空场”契约用其原始历史样例 `389:15` 进行闭环冒烟。重新分类、
左右镜像恢复和实际 target slot 绑定均与契约一致。受限搜索配置为 1 条摩擦
序列、45 秒、3 个粗代理父分支、每支最多 4 次 MADS 轮询：

```text
粗代理候选                  4,305
首撞两个目标之一的分支        605
进入 MADS 的父分支              3
严格 PhysX 回放次数             99
结果                 NOT_FOUND_WITHIN_BUDGET
```

即：在该配置下没找到同时满足“双目标实际出界 + 空场拓扑 + 合规”的路线。它
**不是**物理无解结论，尚未做三摩擦认证，也不允许把失败回退成无约束清壶。

### 已修正的父分支覆盖缺口

原始排序只按总攻击分数取前三条。这个 K8 样例中容易先撞到的 target 11 几乎
垄断了高分支，导致虽然目标集合是 `(11, 13)`，实际三个 MADS 父分支都先撞
11；这不构成对双飞首碰拓扑的充分覆盖。

现在选择器会先各保留一条“先撞 target 11”与“先撞 target 13”的父分支（并尽量
保持旋转方向不同），其余名额再按攻击分数补齐。该修正后的同预算复跑仍为
`NOT_FOUND_WITHIN_BUDGET`，99 次严格回放；所以这次失败不能再归因于“只搜索
了其中一颗壶”。

失败报告也会显式给出：合法严格回放数、合法候选中最少剩余目标数、以及在该
层级下最小的拓扑差异。这样下一步先知道是“没双清”还是“已双清但下一局面不
对”，再决定改粗代理排序还是放宽/细化特定终局分支；不能盲目加大搜索预算。

### 本夹具的实际失败位置（修正覆盖后）

同一受限配置的 99 次严格 PhysX 回放全部规则合法。最好的合法候选已经让两个
实际绑定目标都出界：`bestLegalTargetsRemaining=0`。但仍有
`bestLegalTopologyMismatch=1`，失败项是 `macro`，并清掉了 1 颗己方壶。

所以这条证据只支持如下结论：**该搜索已经能打成合法双飞，却没有打成此数据分支
要求的“清双后 EMPTY”整体形态。**它不支持“这条双飞无解”，也不支持把“清双”
单独升级成可部署战术。下一轮若继续，应先分析这个 `macro` 失配的碰撞链，再决定
是否为“保留/不保留己方壶”的不同后继形态分开建父动作；不能直接加大 MADS 预算。
