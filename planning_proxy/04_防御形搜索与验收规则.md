# 防御形搜索与验收规则

## 这份文档解决什么问题

这里规定的是我方先手、非扫冰条件下，规划器如何搜索第六至第八颗的防御落点，以及怎样判断一个防御形真的值得用。

核心原则只有一句：

> 防御形不是几颗壶“看上去摆得不错”，而是对方最后一颗在已知搜索预算内，既不能进按钮区，也不能比我方最近壶更靠近中心。

所有“能用”的结论都必须经过严格 PhysX 回放和多条摩擦序列；白盒粗代理只负责快速排除明显无希望的路径。

## 先统一几个词

| 词 | 这里的含义 |
| --- | --- |
| 中心锚 | 停在大本营中心附近、负责让对方必须先解决的己方得分壶。 |
| 中线守壶 | 前方中线上的己方壶，参考位置 `(2.375, 7.15)`；它挡住最直接的进营路线。 |
| 左门 / 右门 | 中线守壶与中心锚之间左右两侧的前方保护壶；它们让对方无法从左右两条常用线路直进或轻碰。 |
| 双门 | 左门和右门同时存在。 |
| 防御形 | **位置范围和相对关系**，不是要求四颗壶逐厘米落在同一个点。最终出手只要落入被验证的范围、并满足角色关系即可。 |
| 对方已处理 | 对方壶物理出界，或在前五次投壶的保护期内被送到边缘废球区 / 大本营后方废球区；详见 [中线控场与残局防御策略](03_中线控场与残局防御策略.md)。 |

## 最终要守住的四个角色

目前唯一通过较强反证筛查的最终防线是：

```text
投壶方向
    ↓

              中线守壶 G

        左门 L         右门 R

              中心锚 A
```

参考基准坐标为：

| 角色 | 参考位置 `(x, y)` | 作用 |
| --- | --- | --- |
| 中线守壶 G | `(2.375, 7.150)` | 把正面线路抬高。 |
| 中心锚 A | `(2.375, 4.880)` | 占住按钮附近，要求对手不仅“进营”，还要比它更近。 |
| 左门 L | `(1.920, 6.120)` | 堵住左侧绕进 / 轻碰线路。 |
| 右门 R | `(2.830, 6.120)` | 堵住右侧绕进 / 轻碰线路。 |

这四个位置是基准点，不是当前代码可随意放宽到 20 cm 的通用容差。当前已知情况是：

- 中心锚沿上下左右各偏约 `13 cm` 的四个单点试验，初步筛查仍未找到反例；
- 中线守壶横向偏约 `12.5 cm` 时，出现稳定反例；
- 双门整体放得更外、更前时，出现稳定反例；把门收向内侧、后侧则在初步筛查中通过；
- 因此，正式范围应由下一轮九条摩擦序列的边界试验定稿，不能把“基准点安全”误说成“附近都安全”。

## 什么时候搜索这个最终形

### 我方第六、七颗：建立或修复，不宣称已守住

第六、七颗的第一目标仍是处理对方上一颗有效壶；处理成功后才把出手壶导向中心锚、守壶或一个门的位置。此时允许搜索多个过渡形，例如红圈错层、左/右外壳、单侧护门。

这些形状的作用是把局面往最终四角色防线推进，**不是**最终安全证书。

### 我方第八颗：必须补齐第四个角色

若我方第八颗出手前，场上已经有：

1. 中心锚；
2. 中线守壶；
3. 左门或右门；

则第八颗应优先处理对方第七颗，再补上缺少的另一侧门，完成“双门”。此时才可把“对方末手难以反超”作为搜索目标。

反过来，如果我方第八颗投完后场上**只有三颗**己方壶，就不能把它称为已完成防御。我们已经单独测试了“三壶中心锚 + 宽双门 / 窄双门 / 单侧内盖”等静态三壶方案，均能被对方末手找到较稳定的反击。因此三壶只是一种过渡局面，不能替代四角色防线。

## 每一手的搜索规则

规划器不是先固定一个落点再强行打到那里，而是按下面顺序搜索。

### 1. 先处理对方上一颗壶

- 前五次全局投壶内：严格遵守自由防守区规则；对方普通守壶若不能出界，就把它推到边缘废球区，不以犯规清壶换取布局。
- 保护期结束后：优先物理打出界；若会明显撞散己方布局，才比较“战略出界 + 保住防线”的方案。
- 对方壶只是被撞离红圈、但仍可得分或参与碰撞，不算已处理。

### 2. 再给出多个防御目标，不把一条路径押到底

按我方当前在场壶数，粗筛会同时准备不同的目标区域：

| 当前局面 | 搜索重点 |
| --- | --- |
| 只有 1 颗己方壶 | 补中心锚或第二颗红圈壶，同时保留中线守壶。 |
| 有 2 颗己方壶 | 补前方守壶或一侧门，避免两颗红圈壶聚堆。 |
| 有 3 颗己方壶，且轮到我方第八颗 | 明确搜索缺失的另一侧门；只有完成 G+A+L+R 才算最终合格。 |
| 结构已被拆掉 | 先看哪一个角色缺失；补角色比把壶堆得更靠中心优先。 |

左右门是可镜像的：如果左侧通道被障碍堵住，先放右门；但最后一颗应优先补回左门，而不是再叠一颗右门。

### 3. 粗筛只收束空间，严格 PhysX 决定能不能提交

1. 白盒粗代理枚举连续的初速度、横向初值和旋转参数，默认首轮约 `4305` 条候选；
2. 保留能清目标、不中规则红线、并朝防御角色区域靠近的少量区域；
3. 对每个区域在严格 PhysX 内做局部扰动精修；
4. 每条候选必须跨多条摩擦序列复核，检查所有旧壶的 PhysX 身份和 yaw；
5. 最后一手只输出真正完成四角色防线的候选。普通三角、外壳、红圈后备在最后一手只能作调试信息，不能作为最终提交答案。

## 路线如何排序

所有候选先过硬约束，再排序。硬约束不满足就直接淘汰：

1. 不触发自由防守区犯规；
2. 需要清指定对方壶时，该壶在每条严格摩擦序列下都已处理；
3. 己方出界数不得超过对方实际出界数；出手壶和场上已有己方壶同等计数；
4. 若是我方第八颗，必须完成中心锚、中线守壶、左门、右门四个角色；
5. 在所有摩擦序列下都成立，不能只挑一条“好看”的结果。

通过硬约束后，按以下顺序优先：

1. 最差一条摩擦序列中，己方留在大本营内的壶更多；
2. 三条序列的平均营内己方壶更多；
3. 对方被物理清出的壶更多；
4. 防御角色离各自目标区域更稳、撞击链更短。

这意味着“对方已经被清光”时，系统也不会盲目选一条把己方壶撞散的路线；会优先保留更多可得分壶和完整防线。

## 如何验收一个候选防御形

对方末手验证必须同时覆盖两类进攻：

| 对方尝试 | 为什么必须测 |
| --- | --- |
| 直进 / 旋进 | 测试是否能绕过守壶直接进入按钮区。 |
| 先撞己方守壶 | 测试是否能借碰撞把中心锚撞开、自己滚到更靠中心的位置。 |

对于每条严格候选、每条摩擦序列，都拒绝以下任一结果：

1. 对方最终停入按钮区（到中心距离不大于 `0.145 m`）；
2. 对方最终比仍在场的任一最近己方壶更靠中心；
3. 己方壶全被清掉而对方壶还留在场上。

验证分两级：

- **初筛**：多条直进 / 撞击父路线，每条展开局部扰动，并使用 3 条摩擦序列。它用于快速淘汰明显会破的球形。
- **升级验收**：扩大父路线数，使用 9 条摩擦序列。当前中心锚双门完成了 `10` 个父路线 × `27` 个局部候选 × `9` 条摩擦序列，即 `2430` 次严格 PhysX 回放，未发现反例。

这仍是有限搜索验证，不是连续参数空间上的数学证明。对手若只能依赖极窄、对输入和摩擦都极敏感的单条路线，实战风险和“多数参数附近都能打进”的路线不同；因此还要测下面的局部稳定性。

## “对手也许能打进，但很难精确打中”如何量化

对每一条能形成反例的对方出手，在它周围做小扰动：

```text
速度：    原值 ± 0.06
横向初值：原值 ± 0.06
旋转：    原值 ± 0.75
```

组合后有 `27` 个邻近输入；每个输入再跑 `9` 条摩擦序列，共 `243` 次严格回放。

应记录两件事：

- **破局率**：243 次里有多少次仍触发“进按钮 / 比我方更近 / 清空我方”。
- **稳定破局输入数**：27 个邻近输入中，有多少个在 9 条摩擦序列下全部破局。

当前的工程判定建议是：

- 只要出现一个稳定破局输入，或破局率达到约 `10%`，该防御范围就视为不合格；
- 若没有稳定破局输入，且破局只发生在极少数摩擦—输入组合，才可以把它标为“可接受但需继续扩大验证”；
- 最终上线前仍要把通过的范围和对局中可能残留的敌方壶一起复核。

这是工程风险门槛，不是假装已经有了理论必胜证明。

## 已得到的证据

| 球形或变体 | 结果 | 结论 |
| --- | --- | --- |
| 双红圈错层、左/右三角、左/右外壳 | 对方末手可找到反例 | 只能当过渡形。 |
| 中心锚 + 中线守壶 | 可被从侧面或碰撞拆开 | 不够。 |
| 中心锚 + 中线守壶 + 单侧门 | 仍可被另一侧进入或拆锚 | 不够。 |
| 三壶宽双门、窄双门、单侧内盖 | 9 条摩擦序列下均出现反例 | 三壶不能替代四角色。 |
| 中心锚 + 中线守壶 + 左右双门 | `2430` 次严格 PhysX 回放未发现反例；对方最接近中心约 `0.476 m` | 当前唯一进入“可用候选”的最终形。 |
| 中线守壶横向偏约 `±12.5 cm` | 局部 243 次扰动中破局率约 `35% / 47%` | 守壶横向位置不能放宽到这个量级。 |
| 双门整体外张、前移 | 局部 243 次扰动中破局率约 `33%` | 门不能过外、过前。 |

因此目前实际可用的结论是：**用严格 PhysX 把我方第八颗收束到四角色防线；没有补齐双门就不把它当成“已防住”。**
