# 中线守壶到残局球形：研究与验证路线

## 先把术语说准

代码中的 `shot_index` 指一局内的**单次投壶序号**，范围是 `0..15`；不是“第几回合”。

- `0..4`：全场前五次投壶。自由防守区和中线规则有效。
- `5..15`：第六次投壶及以后。中线守壶不再受该规则保护。

若我方先手，前三次出手是总手数 `0、2、4`。因此“前五手布置出三颗己方壶”准确地说是：在我方总手数 `4` 投完时，理想情况下场上已有一颗中线守壶和两颗营内壶；随后对手在总手数 `5` 有一次先动机会。不能把这一点误写成“第六手结束时球形天然不变”。

## 规则能提供什么，不能提供什么

第 1 手把己方壶放在中线自由防守区，例如 `(2.375, 7.15)`。在总手数 `0..4` 内，对手可以击打、也可以沿中线移动它，但不能：

- 把它撞离中线；
- 把它撞出自由防守区（包括撞进大本营）；
- 把它撞出界。

所以这颗壶不是不可触碰的盾牌，而是一个在前五次投壶内不能被彻底拆掉的中线路障。

## 目标不是“每手都清壶”

目标改为：在每次严格 PhysX 搜索中，先满足规则和安全，再优先让局面接近少数预先验证的残局球形。对手能够击打不代表他容易破局；真正要测的是他破解一个球形所需的可行出手范围是否很窄，而我方维持球形的可行范围是否较宽。

目前定义了三种三壶初始模板，见 `endgame_shapes.py`：

| 名称 | 三颗己方壶的参考位置 | 目的 |
|---|---|---|
| 中线锁门 | 中线守壶 `(2.375, 7.15)`；红圈 `(1.95,4.86)`、`(2.68,4.44)` | 入口有路障，营内两壶前后错开，避免直线双清。 |
| 左右分离 | 中线守壶；红圈 `(1.90,4.80)`、`(2.85,4.95)` | 两颗得分壶分居左右，对手通常只能优先处理一边。 |
| 斜向夹心 | 中线守壶；红圈 `(2.12,5.20)`、`(2.70,4.43)` | 两壶斜对角，减少同一直线上的连锁碰撞。 |

坐标是“吸引目标”，不是要求毫米不差地摆到那里。模块会从己方所有在场壶中选择最像守壶和两个红圈槽位的三颗，计算连续误差；额外己方壶可以保留。若敌方壶进入红圈，则该模板直接视为未成型。

## 评价一条候选路线的次序

对第 2～5 次相关出手，顺序应为：

1. 一票否决：自由防守区/中线犯规，或多条摩擦序列下出现不稳定结果；
2. 优先清除敌方当前最危险的营内壶；
3. 不清敌时，优先把己方新壶放进红圈，或把现有壶推向模板槽位；
4. 同样安全时，选使“离某个模板的距离下降最多”的路线；
5. 不为凑模板牺牲已经形成的得分壶或中线守壶。

“同时清敌、进红圈、完全不碰己方壶”是最高分结果，不是硬条件。物理上三者不能兼得时，应在安全和计分间做选择，而不是输出无意义的固定直线球。

## 必须完成的验证，完成前不宣称稳赢

每个模板至少做以下四类严格 PhysX 测试：

1. **可达性**：从中线开局及若干对手应对出发，我方能否在前三次己方出手后形成模板；
2. **第六次投壶冲击**：对手先动时，能否一手拆掉红圈优势；
3. **残局反击**：从相近球形开始，交替完成剩余出手，测对手的最佳破局与我方补救；
4. **误差宽度**：每条路线用多条摩擦序列和局部输入扰动复核，记录“仍保持领先”的输入范围。

最终保留的模板不应是“画面看起来好看”的球形，而是：我方更容易到达、对方更难稳定破解、并且在扰动下仍有补救路径的球形。

## 当前代码状态

- `endgame_shapes.py`：三种模板、连续局面匹配、红圈敌壶惩罚；尚未改变线上选球行为。
- `tests/test_endgame_shapes.py`：模板识别基本回归。
- 现有 `strict_refine.py`：仍是最终物理和规则裁判，不能被模板评分替代。

下一步应当写“模板可达性 + 对手一手破局”对抗脚本，先用严格 PhysX 得到数据，再决定是否把模板评分接到正式选球排序里。
