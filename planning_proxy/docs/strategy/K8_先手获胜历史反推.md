# K8 先手获胜历史反推（NWNHT）

## 结论

K8 不应使用“见对方营内壶就清”的默认策略。历史先手得分的终局，主要是**保住或形成己方营内得分层**；清壶只有在清掉关键敌壶后同时留下己方有效得分壶时才值得作为目标。

这里的 K8 是先手自己的第八壶（全局第 15 壶前）。统计终局标签时，已经包含对手最后一壶后的实际结果。

## 数据范围

- 原始 K8 记录：10,873 条。
- 先手该局得分：2,452 条（22.6%）；blank：1,432 条；对手得分：6,989 条。
- 能同时映射到 v2 状态、战术动作和出手后完整盘面的记录：5,532 条；其中先手得分 1,286 条。
- 后者用于 `S8 -> G8` 反推；它是完整动作标注子集，不能把它的比率直接当全库因果胜率。

## 赢方打完 K8 后的盘面

在 1,286 条先手得分样本中：

- 807 条（62.8%）仍是**拥挤营**；
- 328 条（25.5%）是**己方营内控制**；
- 130 条（10.1%）是**己方中线/受保护构型**；
- 其余类型合计仅 21 条。

这说明：先手获胜的 K8 常常不是把场面清空，而是让对手末壶仍需处理多壶、遮挡或己方得分层。

## 可直接进入 K8 候选库的第一条边

对 `S8 = K8_V2_OPPONENT_HOUSE_THREAT_94`：

```
单清对方关键营内壶
  -> 己方前左 1 壶 + 前右 1 壶
  -> 对方营内 0 壶
  -> 己方营内控制
```

- 历史结果：10 / 24 条先手得分（41.7%）。
- 得分样本覆盖 4 个独立比赛折。
- 这是**完整终局轨迹**统计：历史里对手已打完最后一壶。
- 运行时要镜像：关键敌壶在左侧则目标终局应为相应左右镜像，不能死用“前左、前右”的绝对坐标。
- 物理合同：指定对方营内目标壶必须出界；出手壶/己方残留壶必须使前左与前右得分槽各保留一枚；精细落点以被清目标壶前方的相对滚位生成，不能跨局固定成一个全局点；然后必须跑本地 PPO 的最后一壶反击搜索。

它比“单清后仅留一枚外侧壶”更符合历史赢方常见的多层营内盘面；但这只是候选优先级，
不是已证明的优势，更不是安全终局证明。

### 本地 PPO 反例（不能自动启用）

历史样例 `6060:15` 在本地严格 PhysX 下可以命中“清敌壶 + 前营双壶”几何合同；
固定 K8 后先手暂得 `+2`。但本地确定性 PPO 的第十六壶将最终结果翻为先手 `-1`。
因此该 G8 当前仅是**历史候选和反击反例**，没有 PPO 通过收据，不能进入自动终局推荐。

### 反解漏解审计（2026-07-18）

同一 `6060:15` 壶面、同一动态相对目标（清走目标壶后，出手壶落入其前方 10 cm 圆区）下，
当前求解链在 20.1 秒内找到并通过三条 PhysX 摩擦种子的动作
`(v,h,w)=(5.72,-1.98,7.3714)`。

- 全局粗格排名第一的动作能清目标壶，却不满足最终滚位合同；
- 命中解来自“粗代理局部细化 -> 严格 PhysX probe”的第 2 条候选，而非把碰撞过程交给 Newton 硬迭代；
- 因此这个实例以前的“未命中”不能归因为物理无解；目前该目标的失败原因是 PPO 末壶反击，而不是反解预算。

这不推出所有类别都已无漏解。每个 `NOT_FOUND_WITHIN_CURRENT_SEARCH_BUDGET` 都仍应保留为
“当前链未找到”，并记录是粗筛无首撞分支、严格 probe 被拒，还是 MADS 局部搜索超时。

这些是候选 `G8`，不是保证命中。它们都还需以当前实际壶位生成精细的落点/清壶绑定，再由严格 PhysX 和 PPO 末壶反击筛查。

## 对当前状态机的约束

1. K8 候选必须包含**完整出手后盘面谓词**，不能只说“打某个点”。
2. `对手营内威胁` 时，优先顺序应是：
   - 清关键敌壶并留下至少两层己方营内得分；
   - 清关键敌壶并留一枚己方受保护得分壶；
   - 只有前两者均没有当前预算内候选时，才考虑单纯清壶/blank 目标。
3. 任何候选先经过粗代理找初值，再用严格 PhysX 检查完整盘面；对手最后一壶用本地 PPO 搜反击。
4. PhysX 在给定预算内没有找到候选，只能表示当前搜索未命中，不能说该历史目标物理无解。

## 证据边界

- 上述数字是 NWNHT 历史轨迹的条件统计，不能单独证明因果或“稳定赢”。
- 它足以把 K8 候选从凭直觉的清壶脚本，收缩为历史赢方确实到达过的完整 `G8` 盘面。
- 稳定性验收仍是：当前局面严格 PhysX 命中目标盘面后，本地 PPO 的最后一壶无法把结果翻成对手得分；再做多种随机种子复验。
