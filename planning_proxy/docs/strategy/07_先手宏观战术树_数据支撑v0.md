# 先手宏观战术树（数据支撑 v0）

## 结论先行

这份树可以作为先手 AI 的**离散目标层**：先识别 47 个宏观状态，再决定当前要维持、削弱还是转移哪一种壶形，最后由严格 PhysX 搜索具体 `v/h/w`。

它不能被读成“历史中胜率高的叫球就是最优动作”。NWNHT 记录的是观察数据，强队实力、此前 end 和比赛过程都会混入；因此每个分支都分为：

- **数据支持候选**：样本量足够，整场胜利关联和本局得分差均不低于筛选门槛；
- **反证/不可直用**：虽有胜局关联，但常把局面留在同一或更差的宏观状态；
- **PhysX 必验**：中线壳、高密度营内或低支持壶形，离散层不规定具体撞击链。

状态识别与数值阈值见 [先手宏观状态数值规范](../training_data/nwnht_curling/FIRST_PLAYER_MACRO_STATE_NUMERIC_SPEC.md)。候选统计来自 10,873 个完整 end、86,984 个先手决策；全局“该 end 首手方最终赢整场”的观察比例为 53.26%。

## 运行时总流程

```text
本地壶坐标 + 先手第 K 次出手
  → FIRST_Kk_宏观状态
  → 查本树：当前目标 / 候选意图 / 禁止误读
  → 本地规则过滤（FGZ/no-tick）
  → PhysX 生成并验收能达成目标的 v/h/w
  → 对手回应后重新识别下一状态
```

其中 K1..K8 是先手自己的第 1..8 次出手，对应总第 1、3、…、15 手。比分、局号和胜负不进入状态；历史胜负只用于离线筛边。

## 先手的四个宏观目标

| 当前结构 | 离散目标 | 不应误读成 |
| --- | --- | --- |
| `OWN_HOUSE_CONTROL` | 保住或加厚己方营内控制，同时不给对方最容易的直线处理。 | 后方壶已绝对安全。 |
| `OPPONENT_HOUSE_THREAT` | 优先改变“对方最近营内壶占分”的几何事实；能否清出、滚位、raise 或穿门由 PhysX 比较。 | 一律高速清壶。 |
| `*_CENTRE_SHELL` | 识别为“壶前有壶”的困难结构，比较两翼、soft hit-and-roll、raise/promote、清守壶等路线。 | 中线守壶是无敌盾，或一定要直线清壶。 |
| `CROWDED_HOUSE_SEARCH_REQUIRED` | 把局面交给多路线 PhysX：优先评估能否减少对方得分层、保留己方层或提高反击难度。 | 清场一定优于保留复杂度。 |

公开顶尖队资料支持两项总方向：前场守壶与营内得分层可以用来制造压力；中线堵塞时可向两翼、hit-and-roll、raise/promote 或穿门 draw 展开。资料同样明确反对把中线守壶当绝对保护。[公开证据树](05_Team_Gushue公开战术树_证据版.md)

## 反证：不能直接部署的高关联边

下列动作曾在胜局中出现，但**不应仅凭统计作为策略**：

| 当前状态 | 观察动作 | 为什么不能直用 |
| --- | --- | --- |
| `K3_OPPONENT_CENTRE_SHELL` | `TAKEOUT` | n=59，约 49.15% 仍留在对方中线壳；数据没有证明它有效打破壳。先比较两翼、清守壶、soft hit-and-roll、raise/promote。 |
| `K6_GUARD_EXCHANGE` | `CLEARING` | n=114，57.02% 后继变为 `K7_OPPONENT_HOUSE_THREAT`；不可把它作为“改善局面”的离散目标。 |
| `K7_GUARD_EXCHANGE` | `CLEARING` | n=55，70.91% 后继为 `K8_OPPONENT_HOUSE_THREAT`；不部署为默认分支。 |
| `K7_OPPONENT_HOUSE_THREAT` | `CLEARING` | n=154，72.73% 仍是 `K8_OPPONENT_HOUSE_THREAT`；只能当 PhysX 的一个处理候选，不是宏观目标。 |
| `K1_EMPTY` | `THROUGH` | 虽然整场胜局关联很高，但本局结果常为对方得分；已被“本局平均得分差”筛掉。说明不能只用最终胜负挑动作。 |

## 没有候选动作的状态如何处理

33 个状态没有同时满足“支持度、整场胜利关联、本局得分差”的候选意图。它们不是无解，而是当前公开数据不足以给出可信离散处方：

```text
LOW_SUPPORT_SEARCH_REQUIRED
    → 不复用少样本历史动作
    → PhysX 比较本地合法的低风险候选

OPPONENT_HOUSE_THREAT（无稳定候选的 K）
    → 目标固定为改变对方当前营内占分
    → PhysX 比较直接处理、hit-and-roll、raise/promote、穿门 draw、先清守壶

GUARD_EXCHANGE（无稳定候选的 K）
    → 不默认清场
    → 比较继续建立己方层、两翼展开或处理真正阻碍壶
```

## 接入 PhysX 前的硬门

任一“候选意图”都必须依次通过：

1. 本地 FGZ/no-tick 规则过滤；
2. 粗代理找可达目标区域，不把历史叫球当坐标；
3. 严格 PhysX 多摩擦序列验证终局结构；
4. 对 `*_CENTRE_SHELL`、`CROWDED_*` 和 K8，运行对手最后一壶反击搜索；
5. 若候选未通过，回退到同状态的其他 PhysX 可达意图，或标记为 `SEARCH_REQUIRED`，不强行执行统计动作。
